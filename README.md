# Meridian Intelligence

A state-of-the-art interactive web application built to showcase Meridian Intelligence's capabilities through immersive 3D experiences, dynamic particle networks, and highly responsive design.

## Overview
Meridian Intelligence is a next-generation landing page built with React, Three.js, and Vite. It features a fully responsive, visually stunning interface that leverages WebGL to deliver high-performance 3D graphics and micro-animations, providing users with a premium browsing experience.

## Technologies Used
- **Frontend Framework:** React 19
- **Build Tool:** Vite
- **3D Graphics & Animation:** Three.js, React Three Fiber, React Three Drei
- **Motion & Interactions:** Framer Motion
- **Particle Effects:** tsParticles
- **Icons:** Lucide React
- **Styling:** Vanilla CSS, clsx

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (Node Package Manager)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/meridian-intelligence.git
   ```
2. Navigate to the project directory:
   ```bash
   cd meridian-intelligence
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the development server, run:
```bash
npm run dev
```
The application will be available at `http://localhost:5173` (or the port specified by Vite).

### Building for Production
To create a production-ready build:
```bash
npm run build
```
The optimized files will be generated in the `dist` folder.

## Best Practices Implemented
- **Component-Based Architecture:** Modular design using React components for maintainability and reusability.
- **Optimized 3D Rendering:** Efficient utilization of Three.js via React Three Fiber to maintain high frame rates.
- **Responsive Layout:** Adaptive design ensuring seamless experiences across all device sizes.
- **Modern Tooling:** Utilizing Vite for incredibly fast hot-module replacement and optimized production builds.
